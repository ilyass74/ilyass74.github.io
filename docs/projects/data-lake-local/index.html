A complete local data path

etl_local.py separates extraction, transformation, loading and querying. It parses order_date, derives year_month, writes a PyArrow Parquet dataset partitioned by month and queries its files with DuckDB SQL. The repository includes sample input and one processed partition. This gives the later Airflow/MinIO work a concrete filesystem baseline.

Implementation & evidenceetl_local.py

Bound the scope

This is an early batch learning project. The writer does not explicitly clear older output partitions, so repeated runs can retain files and inflate results. There is no incremental ingestion, schema validation, deduplication, orchestration or automated test suite. Its value is the inspectable end-to-end storage transformation, not an unmeasured scale claim.
