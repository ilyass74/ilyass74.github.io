THE ENGINEERING QUESTION

Shape trip records into analytical layers, with explicit quality rules.

Trip data contains invalid durations, missing essential values and records that require investigation. The project organizes a fixed NYC TLC input into reproducible analytical layers instead of computing every visualization from raw files.

Clean and aggregate with known boundaries

The main branch uses Parquet. Silver retains positive passengers, distances above zero and at most 100 miles, nonnegative fares and durations above zero and at most 300 minutes. It derives pickup date/hour and average speed. Gold groups daily trips, hours, payment types and pickup locations. Twelve quality checks print their results, but failures do not currently produce a failing exit code.

An optional Iceberg extension remains separate

The inspected feat/apache-iceberg branch adds a local Hadoop catalog, shared transforms, named tables, snapshot retention, full-refresh reruns and Gold count reconciliation. The dashboard consumes exported Parquet rather than reading warehouse files directly. This branch is not merged into main. The main Bronze/Silver path mismatch remains documented; neither branch establishes a full-dataset performance benchmark.
