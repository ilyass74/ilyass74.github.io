THE ENGINEERING QUESTION

Connect ERP reads and document retrieval through explicit tools.

Business questions can require both live ERP records and policy documents. This local assistant connects those two information paths with explicit tools for stock, sales, customer invoices, retrieval and report generation.

Two sources with different retrieval mechanics

Odoo tools use XML-RPC search_read calls limited to 20 records. PDF/TXT indexing splits text into 800-character chunks with 100-character overlap, embeds with BAAI/bge-small-en-v1.5 and stores business_documents in Chroma. The agent retrieves the two nearest chunks. One tool-call round is followed by a model-composed French answer; report tools write type-specific Word files.

Integration scope, not a production assistant claim

The code demonstrates ERP access, retrieval and tool routing. It has no persistent conversation memory or automated test suite. Reads are limited and not explicitly ordered; repeated indexing can duplicate chunks. Flask debug mode and unauthenticated routes make this a local prototype. Generated index/report artifacts are not copied into this portfolio.

Scope & limitations
