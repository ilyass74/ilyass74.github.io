A coordinated pipeline, with distinct lifecycles

PostgreSQL changes pass through Debezium/Kafka into Iceberg Bronze, then entity-level Silver tables and Gold dimensions, facts and summaries. Airflow sequences 14 tasks, including schema validation, source-to-Silver reconciliation, dbt tests, Gold reconciliation, storage checks and metric publication. The active DAG is manually triggered and Bronze uses availableNow, so CDC transport does not imply continuously running end-to-end transformations.

Cut over at a verified boundary

The MinIO path uses a separate checkpoint and a handoff manifest. Preparation checks committed old offsets against Kafka partition bounds and refuses retention gaps or regression. Bronze MERGE uses topic, partition and offset to make a retried batch insert-safe. The original tables and checkpoint are checked for preservation. Recorded local cutover evidence reports 20 readable migrated tables and all 14 Airflow tasks successful; these are point-in-time observations, not a throughput benchmark.
